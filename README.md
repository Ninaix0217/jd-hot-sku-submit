# 京麦冷启 SKU 提报 Skill

在已登录的 Chrome 中操作京麦「冷启加速器」，使用用户指定的 SKU、热销链接池与图片完成单个或批量提报，并保存可恢复的进度。

## 下载与安装

在本仓库的 Releases 页面下载 `jd-hot-sku-submit-v1.0.0.zip`，解压后将 `jd-hot-sku-submit` 文件夹放入 Codex 的用户技能目录（通常为 `$CODEX_HOME/skills`，Windows 默认位置为 `%USERPROFILE%\.codex\skills`）。文件夹内应直接包含 `SKILL.md`。

也可下载仓库源码，将 `skills/jd-hot-sku-submit` 文件夹复制到技能目录。安装后在新会话中输入 `$jd-hot-sku-submit`，并指定提报材料与范围。

## 工作流程

- 不要求 SKU 与候选链接一一对应，按候选池顺序尝试。
- 填写 SKU 后识别每日额度；上传图片后检查 SPU 重复。
- 每条候选按用户确认的节奏，在总计约两秒内连续点击三次提交；表单仍打开时换下一条。
- 每 50 次失败复查 SKU 状态，避免将 SPU 已存在误判为链接无效。
- 成功须核对当前 SKU 的列表记录，并从实际记录读取绑定链接。
- 遇到每日上限停止整批；通过池指纹、共享游标与提交阶段恢复进度。

完整操作要求见 [SKILL.md](skills/jd-hot-sku-submit/SKILL.md)。网站操作需要当次可用的 CUA 浏览器工具；脚本不是独立运行的浏览器机器人。SKU 输入提取使用 Python 与 `openpyxl`。

同一张图片用于两处上传需要会话中已有用户授权。技能不会自行安排次日任务，也不会更换账号绕过额度。

## 验证

使用支持 `node:test` 的 Node.js 执行：

```sh
node --test tests/submit-engine.test.mjs
```

19 项离线测试覆盖 SPU 重复、每日上限、延迟成功、实际绑定链接、图片上传恢复、共享候选池和断点恢复。离线测试不能证明浏览器实际点击次数与耗时；真实使用时应按工具支持能力核对。提交成功表示已进入审核，不表示审核通过。

仓库仅包含通用技能、脚本及模拟测试，不包含原始 SKU 表、候选链接表、商品图片、浏览器凭据或运行检查点。
