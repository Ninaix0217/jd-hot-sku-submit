## 问题与修正

| 实际问题 | 根因与修正 |
| --- | --- |
| SPU 已存在却继续耗链接 | 过早检查且把未关闭全归为链接失败；改为图片后检查、50 次复查，发现 SPU 重复退回该 SKU 起始游标 |
| 追逐短暂 toast、反复提交 | 非持久反馈增加往返；改用用户确认三击/表单规则，失败不逐条记录 |
| 把“请不要重复提交”和占用混为一谈 | 概括不能替代页面语义；重复/节流不能证明链接占用 |
| 按钮/输入框求值时消失 | 成功异步关闭；换链接前检查，消失先核对当前 SKU，不重发 |
| 最后输入 URL 被误当绑定 URL | 前一响应晚到；从实际成功行读取链接 |
| 查看链接后暂找不到新页 | 新页延迟且未接管；刷新/列页、必要时只读重开一次，确切接管并清理 |
| 文件选择偶发超时 | 事件/页面状态中断；检查图片区域，只补缺失，明确超时最多恢复一次 |
| REPL 函数出现旧引用 | 独立单元与闭包引用旧变量；封装同一状态对象、阶段检查点恢复 |
| 单 SKU 后读了早批游标 | 没有共享池进度；用池内容指纹与最新共享游标，批次记录独立 |
